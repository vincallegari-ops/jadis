# Jadis

Appli d'histoire pour les curieux : une histoire vraie à la fois, sur tous les continents et toutes les époques, jusqu'en 1914. PWA installable, utilisable hors connexion.

- `app/` : l'application (HTML, CSS, JS vanilla, aucun build). Publier ce dossier tel quel en HTTPS.
- `design/` : maquettes du canevas Design.
- `CLAUDE.md` : règles produit, design et corpus.

Test local : `node .claude/serve.js` puis http://localhost:5173
